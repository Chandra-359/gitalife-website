# Instrument images — Bhajan Clubbing vibe cards

Images in this folder are the card art for the four "The Vibe" cards
on `/bhajanclubbing` — they fill each card's media window. While a
card's image is missing, it shows the ambient video loop with a
line-art glyph instead.

## Expected filenames (lowercase, exactly as listed)

| File             | Card               |
| ---------------- | ------------------ |
| `mridanga.webp`  | Live kirtan        |
| `kartals.webp`   | A sattvic rave     |
| `bansuri.webp`   | Free prasadam      |
| `harmonium.webp` | Everyone's invited |

Extensions are tried in the order `.webp` → `.png` → `.jpg`; use one
format per instrument.

## Image guidance

- **Full-scene art works best** — the instrument in its setting,
  landscape orientation (the window is 16:9, images are center-cropped
  to cover it). A dark, moody scene matches the page's plum palette;
  the cards add their own accent tint and scrim on top.
- At least ~1280px wide.
- Keep files lean (< 300 KB each) — they load on the main event page.
  Large uploads should be downscaled/re-encoded (WebP ~80% quality at
  1280px wide is usually well under 100 KB).
